# CubeControl website

Static landing for [CubeControl](https://github.com/MrGariZack/cubecontrol-app), published via GitHub Pages.

- Live: https://mrgarizack.github.io/cubecontrol-app/
- Local preview: open `index.html` or serve this folder with any static server.

## Screenshots

With the desktop Vite server running:

```sh
pnpm desktop
# other terminal, from repo root:
node site/scripts/capture.mjs
```

Uses `http://localhost:5173/?demo=1` (DEV marketing demo) and writes PNGs into `assets/`.
